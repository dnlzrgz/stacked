An overengineered to-do application that only lets you do one thing at a time, built with Svelte.
</p>

## Why

I've been working on a couple of full stack projects recently and wanted to explore alternatives to React for the frontend. Since I also have been wanting to learn Svelte for quite some time, I gave myself the chance to try it properly with this project.

Because of that, this small application is packed with features like: i18n, PWA support, SSR, Three.js, service workers, and more.

I also wanted a small to-do application that forced me to focus on one task and one task only.

## Features

- Built with Svelte & Sveltekit
- Server-side rendering (SSR)
- Progressive Web App (PWA)
- Offline support & persistent local storage.
- I18n with English, Spanish, and French support
- Three.js animated background
