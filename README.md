# Stacked

An overengineered todo application that only let's you tackle one task at a time made with Svelte.

## Why?

First of all, Stacked is a learning project. For quite some time I have wanted to play more and learn about Svelte and Sveltekit but never have a good opportunity to do so. But lately things have changed a bit and I started working on some full-stack personal projects for which I wanted to add a fast, modern, and responsive frontend.

But I also wanted a simple application that didn't let me jump back and forth between tasks. What I have in front of me is what I have to do at that's it.

## Stack

- Svelte & Sveltekit.
- TailwindCSS.
- Three.js
